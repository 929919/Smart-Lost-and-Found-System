## Story
> As a **student**, I want to filter items by category, location and status so that I can narrow results without reloading the page.

## Acceptance criteria
- [x] Typing in the search box narrows results as you type
- [x] Search matches item name, description and location
- [x] Category and status filters can be combined with search
- [x] Filtering never reloads the page
- [x] A friendly empty state is shown when nothing matches

## Implementation
`assets/js/dashboard.js` holds the filter state and re-renders on change. Filtering is client-side over the cached item set, so it is instant.
