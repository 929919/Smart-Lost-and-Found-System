## Story
> As a **student**, I want to claim an item by proving it is mine so that ownership can be verified before release.

## Acceptance criteria
- [x] A claim can be started from an active found item
- [x] Proof of ownership is mandatory
- [x] The claim records who submitted it and when
- [x] The claim appears in the administrator queue as Pending
- [x] Items already claimed or returned cannot be claimed again
