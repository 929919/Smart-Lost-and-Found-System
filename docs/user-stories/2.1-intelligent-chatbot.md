## Story
> As a **student**, I want to ask an assistant questions so that I can find out about collection and policy without contacting staff.

## Acceptance criteria
- [x] The assistant answers where and when items can be collected
- [x] It explains the retention period
- [x] It explains how to claim an item
- [x] Suggested questions are offered so users know what to ask
- [x] Answers differ appropriately for students and administrators
