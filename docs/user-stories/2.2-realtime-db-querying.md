## Story
> As a **student**, I want the assistant to search the actual item records so that I get a real answer rather than a generic one.

## Acceptance criteria
- [x] Describing an item causes the assistant to search current records
- [x] A match returns the item with its location and shelf tag
- [x] Only Active found items are offered
- [x] A clear message is given when nothing matches
