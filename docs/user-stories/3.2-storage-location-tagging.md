## Story
> As a **campus security officer**, I want to tag where an item is physically stored so that it can be retrieved quickly when claimed.

## Acceptance criteria
- [x] A shelf tag can be recorded against an item
- [x] The tag is visible to administrators and on the item record
- [x] Items without a tag are handled without error
