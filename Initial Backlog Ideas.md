## Initial Backlog Ideas

1. **As a user,** I want to create an account and log in securely so that I can track my reported item cases.
2. **As a user who lost an item,** I want to submit a detailed report form with category tags so that it is cataloged in the system.
3. **As a student,** I want to chat with the virtual assistant to instantly check if my lost object matches any entries in the database.
4. **As a user,** I want to filter the visual items dashboard by category and date range so that I can look for my property manually.
5. **As a campus administrator,** I want to register a found item with a specific storage shelf tag to keep physical inventory organized.
6. **As a campus administrator,** I want to change an item status to "Returned" once ownership is verified, archiving the entry from the main dashboard feed.
