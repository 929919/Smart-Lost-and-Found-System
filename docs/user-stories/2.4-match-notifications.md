## Story
> As a **student**, I want to be told when a found item matches my lost report so that I do not have to keep checking.

## Acceptance criteria
- [x] Lost reports are compared against all active found items
- [x] Likely matches appear on the student's dashboard
- [x] The reason for each match is explained
- [x] A student sees only matches for their own reports
- [x] Administrators do not see student match alerts

## Implementation
`assets/js/matching.js` scores category (+3), location (+2), colour (+2), each shared keyword (+2) and date proximity (+1), reporting matches at 4 or above with human-readable reasons.

## Testing
