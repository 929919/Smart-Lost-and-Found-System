## Story
> As a **campus security officer**, I want to attach a photograph when logging an item so that its owner can recognise it.

## Acceptance criteria
- [x] A photograph can be captured with the device camera
- [x] A photograph can alternatively be uploaded from a file
- [x] The captured image can be retaken before saving
- [x] Denied camera permission is handled gracefully and does not block logging

Back-check: the task total matches the 2 day story estimate.

## Implementation
`assets/js/camera.js` uses `getUserMedia` with the rear camera, draws a frame to a hidden canvas and stores the result. If permission is refused, a message directs the user to the upload tab.
