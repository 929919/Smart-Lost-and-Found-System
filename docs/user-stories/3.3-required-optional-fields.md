## Story
> As a **campus security officer**, I want the form to tell me which fields are essential so that records stay consistent.

## Acceptance criteria
- [x] Required fields are marked in the interface
- [x] Submitting without them is blocked with a clear message
- [x] Optional fields can be left empty and default sensibly
- [x] Category and status values are constrained to valid options

## Implementation
Client-side validation in the form scripts; `CHECK` constraints in `db/schema.sql` enforce category, item type and status at the database, so invalid data cannot be stored even if the client is bypassed.
