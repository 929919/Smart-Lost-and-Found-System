## Story
> As a **student**, I want the site to work on my phone so that I can check for my item while I am on campus.

## Acceptance criteria
- [x] Layout adapts from desktop to tablet to phone
- [x] Navigation collapses to a menu button on small screens
- [x] The item grid reflows rather than scrolling horizontally
- [x] Forms remain usable at phone width
