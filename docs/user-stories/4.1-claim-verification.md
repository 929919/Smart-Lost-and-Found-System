## Story
> As an **administrator**, I want to review and approve claims so that items are only released to their real owners.

## Acceptance criteria
- [x] All claims are listed for review
- [x] Each claim shows the claimant, the item and the proof of ownership
- [x] A claim can be approved or rejected
- [x] Approving marks the item as claimed
- [x] Rejecting leaves the item available to others
