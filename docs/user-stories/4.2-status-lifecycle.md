## Story
> As an **administrator**, I want to move items through their lifecycle so that the register reflects reality.

## Acceptance criteria
- [x] Items move Active to Claimed to Returned
- [x] Status can be changed directly from a management table
- [x] Only valid statuses are accepted
- [x] Statistics update as statuses change

## Implementation
`admin.html` with `assets/js/admin.js`; `Claims.markReturned()` transitions the claim and the item together. A `CHECK` constraint restricts the column to the three valid states.

## Testing
