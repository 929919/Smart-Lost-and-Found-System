## Story
> As a **campus security officer**, I want to record an item that has been handed in so that its owner can find it.

## Acceptance criteria
- [x] An officer can record name, category, description and colour
- [x] The location where it was found is recorded
- [x] The item appears on the student dashboard immediately
- [x] Only administrators can reach the logging form
