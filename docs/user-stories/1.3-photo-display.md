## Story
> As a **student**, I want to see a photograph of each item so that I can recognise my property without travelling to the security office.

## Acceptance criteria
- [x] Item cards show the photograph when one has been recorded
- [x] Items without a photograph fall back to a category graphic rather than a broken image
- [x] The item detail page shows the photograph at a larger size

## Implementation
`itemMedia()` in `assets/js/store.js` returns either the photograph or a category gradient. Photographs are stored in the `photo_url` column.

## Testing
Unit: a new item defaults `photoUrl` to empty. Acceptance: AT-2.3, AT-3.7.
