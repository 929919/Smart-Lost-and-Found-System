## Story
> As a **student**, I want to report an item I have lost so that the system can watch for it on my behalf.

## Acceptance criteria
- [x] A student can submit a lost report with name and category
- [x] The location where it was lost is chosen on a campus map
- [x] Submission is blocked until a location is chosen
- [x] The report is attributed to the reporting student
