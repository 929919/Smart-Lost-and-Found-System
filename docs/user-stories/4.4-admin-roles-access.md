## Story
> As an **administrator**, I want administrative functions restricted to staff so that students cannot alter the register.

## Acceptance criteria
- [x] Each page declares the role required to view it
- [x] Students cannot reach administrative pages, including by typing the URL
- [x] Navigation shows only the actions available to the signed-in role
- [x] An account with no permissions is refused access entirely

## Implementation
`assets/js/auth.js` runs in the document head and redirects before any content renders. `assets/js/main.js` builds navigation per role. Accounts with role `none` are sent to `no-access.html`.
