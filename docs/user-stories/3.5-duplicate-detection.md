## Story
> As a **campus security officer**, I want to be warned if an item looks like one already recorded so that the register does not fill with duplicates.

## Acceptance criteria
- [ ] Logging an item compares it against existing records
- [ ] A warning is shown when a close match exists
- [ ] The officer can continue anyway if it genuinely is a different item
