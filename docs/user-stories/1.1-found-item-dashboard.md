## Story
> As a **student**, I want to browse a visual grid of found items so that I can quickly see what has been handed in.

## Acceptance criteria
- [x] The dashboard lists items handed in to campus security
- [x] Each card shows category, location, date logged and status
- [x] A photograph is shown when one exists, otherwise a category graphic
- [x] Only Active items appear by default; Claimed and Returned are filtered out
- [x] Live counts of Total / Active / Claimed / Returned are displayed
